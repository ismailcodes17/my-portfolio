How I start a project

I start with one thing a person can do, then I split the work. The page is HTML. If the page needs buttons and a lot of pieces, I use React. If the page needs to save something, Python talks to Postgres. The browser does not hold the database password.

Game Flix

The chart from Steam has ranks, not names. I ask Steam a second time for the title of each game on the screen. Saved games stay in Postgres after the chart changes. Search calls Steam too, because typing gta has to find Grand Theft Auto, not only the games already on the page.

PokéParty and Close Calls

PokéParty is a team builder. React is the site. Python asks PokéAPI and saves a team of six. Close Calls does the same kind of split with NASA: the picture of the day and asteroids that pass near Earth, with favorites stored in Postgres.
